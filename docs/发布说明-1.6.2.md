# 寒窗 1.6.2 · 你的话先出现，老师再思考

1.6.1 修好了「老师被课件框住」，但发送链路上还有一个体验问题：`api.study.send` 是一次请求-响应调用，渲染层要等整轮模型回复返回后才 `applyDetail`，所以你发出的问题会先“消失”，等老师想完才和回答一起出现。

## 这一版改了什么

- **发送即显示**：点「发送」后，先把你这句话追加到当前会话的聊天流末尾，再发 IPC。输入框照常立刻清空，消息不会等模型。
- **老师同时思考**：学生消息下面紧接三个点的「老师正在思考」状态，等待期间界面不再是一片空白。
- **回复到达后无缝替换**：模型返回整份会话详情后，用服务端入库消息覆盖临时消息；临时 id 不会留在会话里，也不会重复显示。
- **失败可回退**：IPC 抛错或返回失败时，撤回这条临时消息，恢复发送前的课堂，并弹出错误提示。
