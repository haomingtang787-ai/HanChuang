# 寒窗 1.6.1 · 老师不再被课件框住

1.6.0 的连续讲解决了「分讲太多、还会漏讲」，但对话提示词仍写死「必须贴着课件原文」「课件不足就明确说缺什么」。结果你问「我还是没看懂，能不能拓展讲解一下 ALU」时，老师只会在第 3 页那句话附近换一种说法，像被幻灯片框住。

## 这一版改了什么

- **课件是主线，不是天花板**：系统提示词从「必须贴着课件原文讲」改成「能对上原文就先对原文，对不上也不必硬套」。
- **允许补课件外知识**：课件没展开的前置知识、工程背景、生活类比、真实硬件例子、反例和边界条件，都可以讲；但必须明确说「课件里没展开，我补一段」，不能伪装成课件原文，也不能和课件已有结论矛盾。
- **「没看懂 / 拓展」单独识别**：命中「没看懂、听不懂、不明白、拓展、展开、多讲、再讲、细讲、讲透」时，追加一条本轮指令：不是再念一遍课件；先判断卡点，至少给一个课件里没有的具体例子，不要用「课件没写所以不能讲」收尾，除非学生要求否则结尾不再出题。
- **纯概念拓展不再强制引用页码**：讲课件里的题或引用原文时仍然要给「第 X 页」依据；纯概念拓展允许先讲透，不为了引用而硬拉回某一页。
- **原有讲解要求保留**：详细讲 350–550 字、结构关系画 Mermaid、短句口语、不编造页码和图公式，全部不变。

## 真实模型验收

用主实例同一把 DeepSeek 密钥、同一套提示词，重放截图里的问题「我还是没看懂，能不能拓展讲解一下 ALU」：

- 回答先点出卡点「乘法、除法、浮点凭什么都能归到加法」；
- 给出课件里没有的 13×5 二进制竖式例子；
- 列出减法、乘法、整数除法、浮点乘加各自怎么退化；
- 补了 Booth 编码、Wallace 树、开方/三角函数的边界，并明确标注「这里是课件外补充」；
- 结尾直接收住，没有再出题。
