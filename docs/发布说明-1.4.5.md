# 寒窗 1.4.5

这一版只动外观，不动功能：**图标重做，界面整体换成一套统一的设计系统。**

## 图标

旧图标是「田字窗 + 蜡烛」，缩到任务栏 16px 就只剩一个通用方块，看不出是什么。

新图标的母题是**夜里那扇还亮着灯的窗**：墨绿夜色底 + 奶白拱窗 + 左下角一盏暖灯 + 窗台。

- 大尺寸（256 / 128 / 64）保留玻璃分格、灯芯、黄铜内边和窗台反光。
- 小尺寸（24 / 16）走专用简化几何：窗体放大、去掉横档只留两扇、左扇整扇填暖色。这样在任务栏、标题栏、Alt-Tab 里都能一眼认出「一扇亮着灯的窗」，而不是一个色块。
- 用像素级校验确认 16px 下暖色区域仍然成立（回归测试里断言暖色像素数量）。

## 界面

把散落的颜色、圆角、阴影收成一套设计令牌，日间 / 夜间共用同一套尺度，只换颜色：

- **纸 / 墨绿 / 黄铜 / 朱砂**四组颜色，分别承担底色、主色、强调与提醒；圆角三档、阴影两档，全局统一。
- **品牌印记**：左栏和欢迎页换成与图标同形的矢量印记，替掉原来红底的「寒 / 窗」汉字方块。
- **左栏**：渐变纸底，当前课程 / 当前课堂左侧有 3px 指示条，层级更清楚。
- **顶栏**：54px 定高，老师状态做成带状态圆点的 chip。
- **卡片**：统一 16px 圆角 + 发丝边 + 柔和阴影；讲课卡左侧一条墨绿边，卡标题前一枚黄铜竖条。
- **输入区**：整条输入行在聚焦时高亮（不再只有 textarea 自己变），发送与主按钮用渐变填充。
- **设置**：下划线式 tab、背景模糊遮罩。
- 细节：细圆滚动条、键盘 `:focus-visible` 焦点环、数字等宽对齐、`prefers-reduced-motion` 下关掉动效。

布局、功能、快捷键、数据一律没变：三栏、左栏可收起、原件对照、备课估价、检查更新都照旧。

## 实测

- `npm run typecheck` 通过；`npx vitest run` **59 个测试文件全部通过**（新增 `tests/design-system.test.ts` 7 项：主题令牌覆盖、尺度只定义一次、输入行聚焦、焦点可见与减动效、品牌印记接入、ico 尺寸齐全、16px 暖灯像素）。
- 在一个**全新隔离数据目录 + 本地假模型**里造了一堂真实的课，逐屏截图核对：欢迎页、课堂（原件对照 / 讲课卡 / 停一下答框）、夜间、设置弹窗、输入区聚焦态。没有动你自己的课程库，也没有产生任何模型费用。
- 打包后静默安装，确认桌面 / 开始菜单快捷方式与任务栏用的是新图标。
