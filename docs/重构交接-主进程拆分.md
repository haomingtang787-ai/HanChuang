1. **只搬代码，不改逻辑**。变量名、判断顺序、错误码、日志文案、时序全部保持原样。
2. **一次只做下文的「一步」**。做完跑三关，绿了就停下汇报，不要连着做第二步。
3. **不动工作区里未提交的改动**：`README.md`、`使用说明.md`、`docs/发布说明-1.5.0.md`、

   以及未跟踪的 `tests/prep-mode.test.ts`。这些是作者手头的活，**提交时用 `git add <具体文件>`，禁止 `git add -A`**。
4. **不新增依赖，不改 `package.json` 版本号，不重新格式化整个文件**（避免 diff 全是噪音）。
