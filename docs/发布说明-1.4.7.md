# 寒窗 1.4.7

设置里多了「清除数据」，图标也重做了——上一版那枚实心拱，缩到 16px 就是一个色块，你说难看是对的。

## 清除数据（设置 → 预算与数据 → 本机数据）

- **先看再删**：展开确认面板后先列出将删的数量（课件 / 页 / 课堂 / 复习卡 / 错题 / 占用），不让人对着 258 MB 猜自己要删什么。
- **两档范围**：
  - 只清课件与课堂：课程分组、我的习惯、老师人格与记忆都保留；
  - 全部清空：连课程分组、习惯、老师记忆一起清，等于从头开始。
- **默认先备份**：勾着「清除前先自动备份一份」时，会先往 `%APPDATA%\desk-teacher-agent\backups` 写一份完整备份（库 + 原文 + 页面图），后悔了用「从备份恢复」拿回来。备份不含 `settings.json`。
- **模型设置与 API Key 永不删除**：清除只动学习数据，不动你的 DeepSeek 配置。
- **防手滑**：要手输「清除」两个字，确认按钮才点得动；清完界面自动重载，不会残留内存里的旧课件。
- **顺手回收空间**：清库后 VACUUM 压缩库文件、清空 `originals` / `artifacts` / `work` 的子项（目录保留），提示里给出实际释放的 MB。

历史上 1.4.4 那张「删课件连带丢课堂」的坑仍然有保护：清除是显式两步确认 + 先备份，不是单点就删。

## 图标：从「一块色块」回到「一扇窗」

上一版为了「高级」做减法，把窗框、窗棂、窗台全删了，只剩一个实心拱——**形体一少，语义就丢了**：16px 看是色块，48px 看像碑。这版按苹果 2025 图标语言（分层、从内部发光、圆角粗线、柔和渐变）重做：

- **保留窗的结构，但用粗线与大形体**：象牙窗框（约 5% 边宽的粗边）、一根竖向窗棂把亮面劈成两扇窗、一道比窗略宽的窗台压住窗脚。窗台是关键——碑没有窗台。
- **分层**：夜墙（纵向渐变 + 四角压暗 + 顶部一层极淡反光）→ 窗（一层内阴影嵌进墙里）→ 玻璃（屋里透出来的暖光，底亮顶柔 + 一圈落在墙上的光晕）。
- **玻璃有厚度**：斜向明暗、顶部内反光、底部灯光汇聚，右下略沉；竖向窗棂与横档（横档只在 ≥64px 出现）。
- **16px 单独一套几何**：不是等比缩小。窗体放大、窗框与窗棂加粗，窗棂两侧各留 ≥3px 亮面，任务栏里仍能看出「一扇亮着的窗」。设计契约里那条 16px 像素断言也跟着改了：暖色玻璃 ≥45 像素、象牙白 ≥14 像素、中间两列竖棂要有 ≥8 行浅色——用像素证明它没有退化成色块。
