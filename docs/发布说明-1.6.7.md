# 寒窗 1.6.7 发布说明

这版主要是把「月度 token 预算」补严，顺带做了一次内部拆分，界面和用法不变。

## 修复

- **每次请求都过预算**：以前只在一次调用开始时检查一次，重试不再检查；现在每一次真正发出的请求（含重试）都会先过预算。到上限时按设置里「到上限就拦住 AI 调用」决定拦截还是只提醒。
- **超时也记账**：请求超时、服务端没返回 `usage` 时，按已发出的提示词估算一笔用量记进当月总量，避免超时的调用从预算里漏掉。
- **失败响应不丢账**：429、5xx 这类可重试的错误响应如果自带 `usage`，也会如实记下；连不上服务器时不编造用量。

## 内部拆分（行为不变）

- 文档文件工具从 `documents/service.ts` 抽到 `documents/fsHelpers.ts`。
- 课堂行解析从 `study/service.ts` 抽到 `study/rows.ts`。
- 素材库与文件夹同步从 `HanchuangApp.tsx` 抽到 `useLibrary.ts`，主组件少了 573 行。

## 已知限制

- 看图请求超时只按文字估 token，不含图片本身，估算会偏低。
- 「本课真实用量」面板里可能混有估算行，具体以设置页「含未返回用量的估算调用」标注为准。
