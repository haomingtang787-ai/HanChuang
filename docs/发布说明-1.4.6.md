# 寒窗 1.4.6

把 1.4.5 的图标再往上提了一档，顺手把界面里几处值得升的细节升了。功能、布局、数据仍然一行没动。

## 图标：从「画一扇窗」到「提纯」

1.4.5 的图标有窗框、窗棂、蜡烛、窗台、黄铜反光——元素都在讲「窗」，但也因此显旧。这一版做减法，只留一个想法：**夜里那扇亮着的拱窗**。

- **拱体就是光本身**：奶白到暖金的渐变实心体，不再用线条画窗框——高级感来自体量与留白，不是描边。
- **光从屋里来**：拱体底部一团柔光，大尺寸还有一圈落在夜墙上的暖光晕；没有蜡烛、没有灯芯、没有窗棂、没有窗台。
- **夜色更深更灰**：纵向渐变（上微亮、下压深），比斜向光安静，衬托拱体的亮。
- **小尺寸同一几何的实心版**：16px 就是「深底 + 奶白拱 + 底部三行暖色」，像素级断言拱体 ≥20 像素、暖色 ≥6 像素，任务栏里仍然一眼认得出。
- **界面里的品牌印记同步换成同款矢量图形**，左栏和欢迎页与应用图标完全一致。

## 界面：值得的几处

- **展示字阶**：品牌名「寒窗」、欢迎页大标题、设置弹窗标题改宋体系衬线（Noto Serif SC → 宋体回退），字距放宽，和拱形印记的气质对齐；正文保持无衬线不变。
- **阴影重做**：从「两层小弥散」改成**贴地 1px + 远处大柔光**的多层弥散，卡片浮起来但不压字；夜间对应加深。按钮悬停不再套卡片大阴影，只留贴地细影。
- **欢迎页**：大卡左下补一枚极淡的墨绿柔光，与右上黄铜光一上一下压住版面；内边距与字号微调。
- **左栏品牌字**：字距 3px → 4px，副标字距放宽，配衬线字。
