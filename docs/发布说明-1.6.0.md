# 寒窗 1.6.0 · 连续讲：不分讲、不按页切，一段一段讲到底

1.5.0 的「按页拆」把每页单独拆成一讲，讲数太多，而且模型少输出几页时会静默漏讲。1.6.0 改成**按内容连续讲**：老师自己判断哪几页属于同一件事，并成一段，讲一段连贯的话；学生只负责点「继续」，直到课件最后一页。

## 这一版怎么讲

- **默认连续讲**：设置 → 我的习惯里的「备课怎么拆」默认是「按内容连续讲（默认：从头到尾一段一段讲）」，仍可切到「按页拆」或「按主干拆」。
- **老师自己并页**：按 12 页 / 12000 字一批交给模型，要求按内容把连续的 1–5 页并成一段，不平均切、不按页机械切。换主题、换问题、换章节才断开。
- **一段就是一段话**：每段 220–420 字连贯口语，先点题，再讲机制或因果，给一个具体例子或反例，最后点出最容易误解的地方；不分点、不加小标题。每段只产出一个讲解片段，不再弹「停一下」。
- **每一页都必须进课堂**：解析时严格校验这一批每一页出现在且只出现在一段里；漏页、重复页、跨批页、段内不连续、段间倒序都会判不合格并重试一次，仍不合格就按页兜底，并在「课件说明」里写明是哪几页，绝不静默跳过。
- **封面、目录、纯图页不再被吞**：没有可提取文字的页会留占位；读图失败的页也会保留，不会从课堂里消失。页序号按入库的 1 起序号标注，第 1 页就是第 1 页（修掉了上一版页码整体 +1 的错位）。
- **顶栏不再报「第几讲」**：连续讲课堂顶部只显示「第 X–Y 页 + 这一段标题 + 一条页进度」，讲课卡头部是「第 X–Y 页 · 标题」；开场也只报页，不再出现「我们从第 1 讲…开始」。
- **主按钮跟着走**：开始上课 → 继续 · 下一段 → 讲完了 · 总结这一课；工具按钮同步改成「这段详细讲」「总结这一课」，输入框提示改成「这一段再举个例子」。

## 价与旧课

- 备课确认框会写「连续讲：老师按内容把 N 页并成若干段，约 M 段；备课调用比导览多，费用会比上面的估价更高」。讲稿一次生成，反复点继续不另花钱；只有追问、出题、总结才另算。
- 1.6.0 之前开的课按原来的分讲界面显示；想试连续讲，重新备一份课件即可。
