# 寒窗 1.6.8 发布说明

在 1.6.7 的预算闸门基础上，补上两处估算准确性和标注问题。

## 修复

- **读图超时把图片 token 也算进去**：视觉请求超时、拿不到官方 `usage` 时，除了提示词文字，还会按图片面积（512px 分块）估算图片本身的 token；没有尺寸信息时用保守保底值。之前只按几行文字记账，看图超时会明显少算。
- **用量面板标明估算**：「本课真实用量」改为「本课用量」。只要本月/本课用量里含估算调用，面板会显示「其中 N 次为估算（供应商未返回用量或请求超时），这几笔按提示词估算，不一定等于账单」。
- 预算闸门保持 1.6.7 的行为：每次真正发出的请求（含重试）先过预算；429、5xx 错误响应带 `usage` 也会记账；连不上服务器时不编造用量。

## 包含的 1.6.7 改动

- 每次模型请求（含重试）前都检查月度预算。
- 超时、供应商未返回 `usage` 时按估算记一笔。
- 内部拆分：`documents/fsHelpers.ts`、`study/rows.ts`、`renderer/hanchuang/useLibrary.ts`，行为不变。
