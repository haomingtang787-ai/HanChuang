# 逐页拆讲（1.5.0）计划

| ID | 行为 | 精确契约 | 涉及文件 | 可观察断言 | 验证 |
|---|---|---|---|---|---|
| P1 | 备课可按页拆讲 | `granularity` 取值 `overview`（默认，原 1–4 讲）/ `page`（每页至少一讲，内容多时一页最多两讲） | `src/study/service.ts`、`src/study/pagewise.ts`、`src/preload/index.ts` | page 模式下 units 数 ≥ 有知识内容页数，session.units 顺序等于页顺序，每讲 source 为该页页码 | 单测 + 假模型跑一份真课件 |
| P2 | 逐页提示词只讲本页 | 每批 ≤4 页原文进提示词；`segments` 1–3 段，source 逐字取自本页；无知识页可跳过并回报 `skipped` | `src/study/pagewise.ts` | 生成提示词含「每一页至少一讲」「逐字」；解析后 unit 的 segment.source 能在该页原文里找到 | 单测断言提示词与解析 |
| P3 | 逐页模式不重复付读材料的钱 | page 模式跳过 digestMaterial，直接按页分批拆；进度 phase=planning done/total 随批次推进 | `src/study/service.ts` | 假模型记录：page 模式请求序列中只有 page-plan 调用，无 digest 调用 | 假模型请求日志 |
| P4 | 界面能选拆法并如实告知代价 | 设置「我的习惯」增加「备课怎么拆」下拉（按主干 / 逐页逐段），选择存 localStorage；备课确认框在逐页模式写明「每页至少一讲，约 N 讲，费用更高」 | `src/renderer/hanchuang/logic.ts`、`SettingsPanel.tsx`、`HanchuangApp.tsx` | 设置页可见下拉；切到逐页后确认框文案含「逐页」；create 请求带 `granularity:'page'` | 隔离实例 CDP 截图 + 请求体 |

验证命令：`npm run typecheck` → `npx vitest run` → `npm run build` → 隔离实例（复制真实数据）跑假模型逐页备课，核对 unit 数/顺序/请求日志。
