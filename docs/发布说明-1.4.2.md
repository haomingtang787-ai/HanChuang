# 寒窗 1.4.2

本地 AI 授课老师的 Windows 桌面版。把课件丢进去，老师一段一段讲给你听，会提问、会总结、会出题。

## 这一版改了什么

**左栏可收起，课件与对话对半**
- 顶栏 `≡ / «` 或左栏标题旁的 `«` 一键收起课程树，整屏只剩「课件 + 对话」
- 面板宽度从写死的 440px 改成占「课件+对话」区域的 50%，窗口拉大、最大化、全屏都保持各一半（实测 986 宽时各 493，1266 宽时各 633）
- 拖分隔条可在 28%–62% 间调，**双击分隔条回到一半一半**
- 收起状态与比例会记住；旧版存的像素宽度自动按对半处理，不会挤成一条
- 修掉一处旧行为：以前「打开课堂」会顺手关掉左栏（那是给窄屏浮层用的），现在只在窗口 ≤980 宽时才收起

**新应用图标**
- 深墨绿圆角底 + 奶白窗棂 + 左下格一盏灯，对应「寒窗」意象
- 图标改成 256/128/64/48/32/24/16 **七档逐尺寸绘制**（不是一张大图缩放），任务栏和桌面小图标不再糊；窗口图标也进了安装包
- 图标由 `scripts/build-icon.mjs` 代码生成，改配色重跑即可

**备课前先看价（1.4.1）**
- 素材行标出这一份备课的大致花费，如 `约 ¥0.01 · 6k–9k`（按页数本地估算，不调模型、不花钱）
- 点「备课」再弹一次价格确认；取消就一个 token 都不花（已实测：取消后该课程课堂数仍为 0）
- 估算依据真实账：82 页 PDF 备成 4 讲约 4 万 tokens

## 下载哪个

| 文件 | 说明 |
|---|---|
| `HanChuang-setup-1.4.2.exe` | 安装版，会创建桌面快捷方式，可自选安装目录（推荐） |
| `寒窗 1.4.2.exe` | 便携版，双击即用，不写注册表（启动稍慢，临时解压） |

两个都是 x64、未签名，首次运行 Windows SmartScreen 可能提示「更多信息 → 仍要运行」。

## 运行前提

- Windows 10/11 x64
- 需要自备 DeepSeek API Key（设置里填）；没有密钥也能导入课件、翻页、搜索原文，但上不了课
- 「用 WPS 打开」按扩展名找本机 WPS，没装则回退系统默认程序

## 数据位置

`%APPDATA%\desk-teacher-agent\library`（SQLite 库 + 课件原件 + 页图缓存），`settings.json` 存 API Key。
换机器时拷走这个目录就能带着课程走；这个目录不进仓库。

## 验证情况

- `npm run typecheck` 干净；`npx vitest run` 56 文件 **333 项全绿**
- 界面冒烟（CDP 驱动真实窗口）：`SMOKE_R6_OK`、`SMOKE_R5_OK`，其中布局脚本也在打包后的便携版上复跑通过
- 便携版实启动窗口标题「寒窗」，静默覆盖安装后版本号 1.4.2.0
