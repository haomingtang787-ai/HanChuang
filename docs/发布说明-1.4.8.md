# 寒窗 1.4.8

图标换了。这次不是再画一扇更漂亮的窗——是换掉「用图案讲窗」这件事本身。

## 为什么前三版都不成立

1.4.5 画拱窗加一盏灯，1.4.6 提纯成一块实心拱，1.4.7 把窗框、窗棂、窗台装回去。三次都在同一条路上加细节，结果一次比一次更像「贴着细线的绿方块」——**32px 以下，窗棂就是一两像素的灰边，窗台就是一个多余的小台阶**。你说的「意义不明、线条也差」，本质是：图标里塞了太多要读的东西。

对着你桌面上的两枚图标看，它们其实很简单：

- **诗窗**：暗红方块 + 一个奶白汉字 + 一圈细内框。没有图形，字就是图形。
- **DeepSeek Harness**：近白方块 + 一整块深色鲸鱼剪影。没有描边、没有渐变，只有形和留白。

两枚的共同点是：两种颜色、一整块形、大留白。没有一个是靠细线画结构的。

## 这一版

**宣纸色的方块上，一枚墨绿的「寒」。**

- **汉字就是那扇窗**。「寒窗」两个字里，「寒」是那间屋子，「窗」是那点光。四版里只有这一版在三十二像素下仍然是一句话，而不是一块色块。
- **字不是系统字体渲染的**：从 Noto Serif SC（OFL）把「寒」的轮廓抽成矢量路径（wght 600，居中对齐、占 78% 视口），打进包里——换台电脑、换套字体，图标和界面里的印记都长得一模一样。
- **小尺寸换字重**：16 / 24px 用同一字族的 850（更厚），细横不会在缩放时消失；32px 起回到 600。这是图标界的常规做法（optical size），不是特例。
- **只有两种颜色**：纸 `#FCF7EA → #EADFC5`，墨 `#16261F`。没有内框、没有阴影、没有玻璃反光；方块边缘只留一道 0.13 透明度的压边，免得在浅色桌面上失去轮廓。
- **界面印记同源**：左栏 34px、欢迎页 60px 的 `BrandMark` 现在就是这枚印章，与应用图标共用同一份字形路径。

## 实测

- `npm run typecheck` 通过；`npx vitest run` **60 文件 358 项全过**。
- 设计契约新增一条：16px 图标必须「纸底 ≥120 像素、墨迹 ≥24 像素、且墨迹落在中央 ≥20 像素」——用像素证明它在任务栏里还是一枚盖了字的纸，而不是一块色块。
- 隔离实例截图核对：欢迎页 60px 印记、左栏 34px 印记、浅色与夜间两套主题都换成新印记。
- 打包后静默安装，确认 FileVersion 与安装目录 exe 图标。
