# 寒窗 1.5.0 · 按页拆讲：一页一讲，一点一点往下讲

这一版加了你说的那件事：**不分大讲，直接把课件拆成一页一讲，按顺序一段一段往下讲。**

## 设置里多了一个「备课怎么拆」

设置 → 我的习惯，最上面：

- **按页拆**（默认，这一版起就按这个走）：每一页单独拆成一讲；一页内容多、有两个独立主题时才拆成两讲，一页最多两讲。封面、目录、版权、致谢这类没有知识内容的页自动跳过，跳过的页码写进「课件说明」，不偷偷吞掉。
- **按主干拆**：整份材料合并成 1–4 讲，先搭框架，细节留到追问；想先看全局时可以切回来。

换完不用重启，下次点「备课」就按新拆法走。已经备好的课保持原样；想按页重来，换一份课件重新备课即可。

## 一讲只讲这一页

- 每讲 1–3 段，每段只抓这一页里的一句关键原文（逐字复制，不许改写、不许跨页合并）。
- 讲解仍是 180–330 字，按「白话 → 机制/因果 → 例子 → 易错」四步走，讲完停一下问一句。
- 备课确认框会写明：「按页拆：每页至少一讲，约 N 讲；备课调用比导览多，费用会比上面的估价更高。」

## 代价与省法

- 讲数就是页数量级（42 页的 PDF ≈ 42 讲），备课调用次数随页数涨，费用和时间都比按主干高——这一点在确认框里先说清楚。
- 按页模式不再额外做一遍「逐段读懂」（digest），这一步的钱和时间省掉了；读图仍然照旧，扫描件该读的图还是会读。

## 几十讲也不会挤爆界面

讲数超过 10 讲时，课堂顶部进度条从「一排胶囊」收成「第 k/N 讲 + 这一讲标题 + 一条细进度条」；左栏课堂行直接显示总讲数。
