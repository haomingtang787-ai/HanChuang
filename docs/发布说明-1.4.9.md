# 寒窗 1.4.9 · 模型只认接口、习惯自己写、任意页都能问

这一版没有动图标和布局，改的是三件「用起来别扭」的事，外加两处你顺手提的界面调整。

## 模型下拉不再出现假名字

- 以前输入框下的模型下拉里写死了 `deepseek-chat`、`deepseek-reasoner` 两个兜底项。`/models` 一拉失败，界面就显示这批名字，还不报错——这就是你觉得「模型不太对」的原因。
- 现在下拉**只列接口真的返回的模型**（你这把密钥拉到的是 `deepseek-flash` 和 `deepseek-v4-pro`）；`/models` 失败时下拉换成「模型列表未拉到 · 去设置里检查地址和密钥」，同时弹一条通知说明失败原因。
- 设置页一打开就会自动拉一次真实模型，chips 点一下就能选，不用再手动点「拉取模型列表」。

## 「个人习惯」从五个下拉改成一块空白

- 节奏 / 讲法 / 一坐多久 / 常用时段 / 要避开，这五个预设全删了。它们写的是别人替你定的话术，模型照着念反而容易跑偏。
- 现在只有两栏：**怎么称呼你**，和一块 160 字的**「想让我怎么教（可以不填）」**。
- 提示词里也改了：只把你写的那段当唯一依据；没写就按默认讲法，明令不许假设你的偏好。真正摸清你靠上课——老师会把观察到的写进「老师记忆」，你勾「确认」才生效。

## 任何一页都能问了

- 以前老师的上下文只有「当前这一讲的讲稿 + 这一讲命中的 3–4 页摘要」，所以你说「第 39 页我看不懂」，它只能回「本讲对照的是第 10、11、17、24 页，我手上没有第 39 页」——这句不是偷懒，是真的没拿到。
- 现在问句里点到页码就会去库里取原文：
  - `第39页`、`39页`、`第 39 页`、`39-41页`（区间最多展开 3 页）、`P39` 都认；
  - 命中的页整段原文一起进提示词，提示词里写明「直接拿它讲，不许说自己看不到」；
  - 库里确实没有那一页时，只说明缺哪一页，不许凭印象编。
- 引用也会跟着走：答完点「对照原文」，跳的就是你问的那一页。

## 顺手改的两处

- **输入框上方新增「详细讲这一讲」**（描边按钮）：不想一段段点，一键把当前这一讲按 350–550 字的细讲规格展开。
- **左栏素材行改成两行**：第一行是课件原标题（最多两行，不再截成「01-…」），第二行小字是备课预估价（`¥0.02–0.03 · 18k–27k`），「备课」和「✕」不再跟标题挤在一起。

## 验证

- `npm run typecheck` 通过；`npx vitest run` 60 个文件 361 项全过（新增「第 39 页原文进提示词」断言，改写习惯契约断言）。
- 隔离实例（复制真实数据）实测：模型下拉只有 `deepseek-flash`、`deepseek-v4-pro`；习惯页只剩称呼 + 空白框；拿本地假模型接住请求，问「第39页我看不懂」，发出去的提示词里确实带上了该页原文（`DDR：带宽=每秒传输次数 × 每次传输的字节数`）。
